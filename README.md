# Aara Store Studio

## Run locally

1. Copy `.env.example` to `.env`. The default API address is `http://localhost:4000`.
2. Run `npm install` once, then `npm run dev`.
3. Open http://localhost:5174 and sign in with the credentials set in `Rugs_Backend/.env`.

The panel edits products, categories, published content pages, brand identity and homepage settings. Use public image URLs; image upload/storage is not yet configured. The backend must be running and connected to MongoDB.
